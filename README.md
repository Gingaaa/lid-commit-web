## ✨ Features Highlighted on the Site

- 📦 **1-Click Download Hub**: Windows installer (`LidCommit-Setup-x86_64.exe`), pre-compiled macOS (Apple Silicon & Intel) binaries, Linux binaries, and source code instructions.
- 🖥️ **Interactive Desktop Dashboard Showcase**: Live interactive preview of `gui.rs` and `dashboard.html` with per-project pause toggles and "Sync Now".
- ⚙️ **Windows Power Options Guide**: Step-by-step instructions to configure *"When I close the lid"* to *"Do nothing"* so background git operations run uninterrupted.
- 🤖 **Interactive AI Commit Playground**: Test diff analysis using Gemini, OpenAI, Ollama, and timestamp-based fallbacks.
- 🛡️ **Safety Guard Overview**: 50+ file safety limit, merge conflict immunity, and clean tree detection.
- 🤝 **Community & Contribution Hub**: Conventional commits guide, PR workflow, and GitHub issue templates.

## 🛠️ Tech Stack

- **Framework**: [Next.js](https://nextjs.org/) (App Router, Turbopack)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Components**: Base UI / shadcn
- **Hosting**: [Netlify](https://www.netlify.com/)

## 🚀 Local Development

```bash
# 1. Install dependencies
npm install

# 2. Run the development server
npm run dev

# 3. Open http://localhost:3000 in your browser
```
